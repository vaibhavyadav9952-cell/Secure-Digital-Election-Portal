How It Works

👤
1. Register

Create an account and capture your face for biometric ID.

📷
2. Face Login

Login using email/password and live face verification.

📤
3. Vote Once

Cast your vote securely. Each voter can vote only once.

🔒
4. Blockchain

Your vote is stored in a tamper-proof blockchain.

Security Features
  • 🔒 bcrypt password hashing - passwords are never stored in plain text
  • 📷 OpenCV + face_recognition library - AI-powered face matching
  • 👀 Liveness detection - prevents photo spoofing attacks
  • 📈 Rule-based fraud detection with risk scoring (0-100)
  • ⛕ Custom SHA-256 blockchain - every vote is immutably recorded
  • 🚫 One vote per user - enforced at both database and session level
